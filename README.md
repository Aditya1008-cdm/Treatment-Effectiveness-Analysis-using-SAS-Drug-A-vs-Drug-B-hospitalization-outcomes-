Clinical Data Analysis Using SAS & SQL.
Performed a Real-World Evidence analysis using synthetic healthcare datasets structured to mirror claims and EHR data.
Built patient cohorts based on drug exposure (Drug A vs Drug B) using treatment start date as the index date.
Conducted baseline demographic analysis to assess cohort comparability.
Defined hospitalization as a real-world outcome occurring after treatment initiation.
Calculated and compared hospitalization rates across treatment cohorts using SAS (PROC SQL, PROC MEANS, PROC FREQ).
Reconstructed longitudinal patient journeys using SQL to identify line of therapy, treatment switching, and persistence.
Addressed real-world data limitations such as missing data and confounding through validation checks and transparent documentation.
Visualized selected summary outputs using Power BI (beginner level) to support interpretation.
